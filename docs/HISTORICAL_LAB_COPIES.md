# Historical Saved copies in the global Test Labs

The source is an explicit Run, selected Branch and reachable Saved Revision.
The selected Branch grants reachability; components keep the revision's actual
owner, including shared pre-fork history. The common read adapter authenticates
the complete lineage and actual native dependencies inside one SQLite read
transaction. It uses the existing repository proofs and native source decoder;
no live Package, Working Draft, original Branch HEAD or prospect catalog supplies
missing historical facts. Missing/corrupt dependencies fail closed, including
on warm proof-cache reads.

field, format, seeding and draw seed, using participant states at the selected

original tournament's results. Native v2 current and authenticated inherited
Edition authorities are supported for ranked main-only fields of 4/8. Existing
legacy knockout/qualification/group contracts remain. Unsupported WC/LL,

Each imported player retains the complete stored 57-attribute sporting record,
potential and its provenance, Form/norm, Sharpness, Fatigue, biography, selected
calendar/week and Health facts with their actual source date. Initial population
and born players resolve through the historically effective Saved sources.
Sporting membership prevents a prepared prospect becoming available before birth.
Unavailable legacy-only metadata of native prospects stays absent/unspecified.
The seven MatchEngine values are an explicit canonical projection of this source,
not a claim that seven values are a complete player state.

A seven-value Initial World without a complete sporting checkpoint is insufficient.
Match/Tournament retain an explicitly absent legacy Health source; if recorded
Health needs unsupported numeric effects they reject the affected import rather
than silently heal the player. Player import requires actual stored Health.
General Lab-to-native-v2 authoring is still blocked by the existing guards.

instead of the source reviewed at submission. The runner now freezes both
scenario and Session identity/fingerprint in submitted variables. Regression

including rejection of detached result display. This supersedes the earlier
no-unresolved-defect statement for that candidate. Final-head hosted acceptance
still applies.
