# Master Classic Bracket Geometry V2

This contract implements the decided classic-elimination geometry in Master Vision
§15.2–15.4 without changing historical Draw Input/Draw v1 readers.

## New-authority contract

All newly persisted Tournament Draw Input commitments use
`tournament_draw_input_authority.v2`.

For one classic bracket:

`seed_count = min(actual_player_count, max(1, bracket_capacity / 4))`

The capacity must be a power of two. The resulting examples are therefore:

- 2 -> 1 seed
- 4 -> 1 seed
- 8 -> 2 seeds
- 16 -> 4 seeds
- 32 -> 8 seeds
- 64 -> 16 seeds
- 128 -> 32 seeds

An explicitly supplied seed count is treated only as an assertion and fails if it
differs from the Master-derived value.

New Draw Input v2 produces `tournament_draw_authority.v2` with
`idealized_seed_tiers.v2` placement.

## Idealized positions and seed tiers

The physical top-to-bottom positions carry stable idealized slot numbers. For eight
positions they are exactly:

`1, 8, 5, 4, 3, 6, 7, 2`

Seed 1 is fixed to idealized slot 1 and seed 2 to idealized slot 2. Later seed tiers
are deterministically shuffled from the frozen draw seed only inside their allowed
idealized tier:

- seeds 3–4 -> idealized 3–4
- seeds 5–8 -> idealized 5–8
- seeds 9–16 -> idealized 9–16
- and so on.

Unseeded players and Q placeholders are then shuffled only over remaining unseeded
physical positions. Country, H2H and rivalry are not draw-protection inputs.

## Initial BYEs

Initial BYEs consume the highest available idealized slot numbers. This makes the
Master example of 28 players in a 32 bracket place four BYEs in idealized
29, 30, 31 and 32.

This is initial-generation behavior only. A later withdrawal-generated BYE must stay
in the vacated physical slot; that belongs to the phase-aware repair work in §15.9–
15.10 and is not implemented by this generation slice.

## Compatibility and next boundary

Historical Draw Input v1 and Draw Authority v1 retain their original seed-count and
placement replay contract.

This slice does not yet claim full Master bracket completion. The immediate next
canonical bracket work is:

1. multiple linked Q1..Qm Qualification brackets using §15.5–15.6 global seed layers;
2. Qualification BYE distribution by idealized layers across Q sections;
3. group Qualification structure from §15.7, while its explicitly deferred tie-break
   and incomplete-group rules remain open;
4. LL creation/fill and external reserves from §15.8;
5. Qualification/Main three-phase redraw/cascade/freeze repair and first-real-match
   replacement cutoff from §15.9–15.10;
6. manual preview/regeneration boundaries from §15.11.
