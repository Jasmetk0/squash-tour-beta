# Beta_Engine Roadmap

## MVP (Foundation)
- Country database + player generation.
- Editable World Tour + Elite Tour calendar templates.
- Entry list engine + qualification/main draw generation.
- Set-by-set match engine (professional format, 11 win-by-2).
- Ranking engine (61 weeks / best 12) + seasonal Race.
- Simulation control commands (next match/round/tournament/week/full season).
- Weekly snapshots + basic season/history archives.
- Minimal web UI for sim controls and core world views.

## V1.1 (Depth & Control)
- Deeper injury model (recurrence/comeback quality).
- Stronger travel burden integration in scheduling/performance.
- Richer archetypes + play-style matchup impact.
- Full World Tour Finals format (8 players, groups + playoffs).
- Expanded nation dashboards and legacy records.
- Stronger commissioner operations, including safer rollback/rerun flows.

## V2 (Intelligence Layer)
- Embedded AI assistant in UI for explanations and admin guidance.
- Natural-language commissioner commands mapped to deterministic backend commands.
- Advanced analytics and balance diagnostics.
- Deterministic-data-based narrative outputs (previews/recaps/storylines).

## Roadmap guardrails
- No realism expansion that weakens deterministic replayability.
- No hardcoded editable world content in business logic.
- UI remains a client over stable backend contracts.
- AI augmentation must not replace deterministic simulation core.
